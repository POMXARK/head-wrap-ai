# head-wrap-ai

Локальная программа: берёт сгенерированную голову (TRELLIS/Pixal3D), обтягивает по ней чистый шаблон с правильной
топологией и постоянной UV, запекает текстуру в UV шаблона; локальный ИИ (Ollama, ComfyUI) сегментирует виды,
судит рендеры и учится на правках. Лаунчер в стиле diskview: один файл `app.py`, stdlib, `127.0.0.1`.

Запуск: `python app.py` → http://127.0.0.1:8770. План и список проблем — [docs/plan.md](docs/plan.md).

Приватность: сервер слушает только 127.0.0.1; запросы с картинками идут только на локальные адреса
(127.0.0.1, LAN), внешний профиль блокируется с записью в журнал. Облачные модели не используются.

## Интерфейс: что есть и что планируется
- **Командная строка** — `python3 headwrap.py status|texture|build|game|all` (весь конвейер после обтяжки, шаги пропускаются, если выход свежий). Это единственный источник логики.
- **Веб-панель** — `python app.py` (профили моделей, журнал, оценки шагов). Страница **/pipeline**: кнопки шагов конвейера (состояние, текстура, сборка, оценка глаз, в игру, всё), живой журнал, таблица оценки глаз (`eye_score.py`) с рендером и 3D-просмотр собранной головы (`model-viewer` с CDN; без интернета страница работает без 3D). Логика только в `headwrap.py`/`eye_score.py`, панель — тонкая оболочка (`pipeline.py`).
- **Windows** — `run.bat` (панель, открывает /pipeline в браузере) и `headwrap.bat` (шаги из командной строки). Нужен Python 3.10+ с `numpy trimesh scipy matplotlib pillow opencv-python-headless scikit-image`; для шагов `texture`/`build`/`game` — данные `work/`, шаблон, игра рядом и LaMa (в архиве репозитория их нет: оценка глаз и просмотр работают по `work/hero1_eye.glb` + `work/eye_open.json`).
- **Skills Claude** — `.claude/skills/head-wrap` (запуск и порядок) и `head-wrap-check` (кадры, живая игра, каталог дефектов); копии лежат и в `remake/.claude/skills`.
- **Плагин Blender (решение)**: не отдельная программа, а тонкая панель, которая вызывает `headwrap.py` через subprocess и открывает результат во вьюпорте; логики в нём нет, чтобы не было двух версий. Пока не написан (в этой среде нет Blender для проверки).

## Два режима
- **Голова** — `headwrap.py` (конвейер) и `session.py` (сравнение вариантов «лучше/хуже»: история, обучаемый оценщик, выбор части `--region ear` или мышью; страница `/review`).
- **Модель** — `model.py` (части любой GLB, импорт, замена, добавление, удаление; страница `/model`). Дальше — сборка из каталога частей в духе Asset Forge (см. docs/plan.md).
- Сервер: `python3 app.py` → http://127.0.0.1:8770

## Файлы конвейера
`wrap_fit.py` (обтяжка) → `bake.py` (запекание) → `colormatch.py` → `cleanneck.py` → `padedge.py` → `lama_seam.py` / `lama_patch.py` → `export.py` (+ `eye_slit.py`, `ponytail.py`) → игра (`pdm_glb2gm.py`). Инструменты на один раз: `lama_uvseam.py`, `smooth_strip.py` (тупики, см. docs/plan.md).
