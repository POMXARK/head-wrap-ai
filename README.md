# head-wrap-ai

Локальная программа: берёт сгенерированную голову (TRELLIS/Pixal3D), обтягивает по ней чистый шаблон с правильной
топологией и постоянной UV, запекает текстуру в UV шаблона; локальный ИИ (Ollama, ComfyUI) сегментирует виды,
судит рендеры и учится на правках. Лаунчер в стиле diskview: один файл `app.py`, stdlib, `127.0.0.1`.

Запуск: `python app.py` → http://127.0.0.1:8770. План и список проблем — [docs/plan.md](docs/plan.md).

Приватность: сервер слушает только 127.0.0.1; запросы с картинками идут только на локальные адреса
(127.0.0.1, LAN), внешний профиль блокируется с записью в журнал. Облачные модели не используются.
