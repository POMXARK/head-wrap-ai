## Журнал визуальных проверок (живое окно Chrome, мышь через xdotool, 2026-11-06)
- Кисть мышью на настоящей голове → выделено 963 вершины; «Сместить» в области → изменилась только область; «Отменить» вернул лицо.
- Замена головы шаблон → hero1 на манекене: масштаб ×2.41, несовпадение кольца 28% — шов виден, нужна сшивка (bridge).
- Найденная ошибка: после отмены замены выделение со старой головы подсвечивало случайные вершины (другая нумерация) → теперь выделение сбрасывается, тест добавлен.
- Неудобство: зум колесом шёл к центру модели, а не к голове → добавлены «К голове» / «Весь вид» и рамка по голове.
- Сшивка `bridge` (A4): полоса треугольников между кольцом донора и кольцом тела; на hero1 несовпадение 28% закрыто, длиннейшее ребро ×0.43 радиуса; снизу в окне шея переходит в тело без щели. Области «по списку» работают только на шаблоне головы (на чужой голове — кистью, сообщение об этом показывается).
- Осталось в A4: подгонка цвета, перенос весов скелета, настоящее тело вместо манекена.
