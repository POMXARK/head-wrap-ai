# Модель целиком из игры в /edit: что работает и что доделать

Статусы: [x] готово, [ ] не начато. P1 — без этого работать нельзя, P2 — неудобно, P3 — улучшение.
Проверка 2026-11-08: чтение кода `edit_api.py` / `edit.html` / `selection.py` + прогон в Chrome на `hero.glb` (17 частей).

## Что уже есть
- [x] «Вся модель» открывается как есть (без манекена): части сливаются в одну сетку, текстуры — в атлас (`_merge_all`), UV вне 0..1 тайлятся.
- [x] Нормали файла, отсечение задних граней, текстура без освещения — лицо без штриховки (ux-review §29–31а).
- [x] Список частей: имена из текстур («Плечо правое»), своё имя ✎, Ctrl/Shift — несколько, подсветка при наведении, «Только эти», «Скрыть эти», «Показать все», «Призраки», «В выделение» (§32–33).

## P1 — ломает работу
- [x] **1. Части пропадают после первой правки.** Сделано: состояние файла держится, пока грани те же (`file_model_state`), сдвинутые вершины и соседи — `vn_moved`, их нормали считает редактор; возврат отменой к модели из файла возвращает части. Тест `tests/test_parts_after_edit.py`; в Chrome: сгладить голову → 17 частей, скрытие, отсечение, текстура без освещения на месте. Было: `mesh()` отдаёт `parts`, `vn`, `cull`, только пока вершины точно равны загруженным (`np.array_equal(HEAD_VN[1], h.V)`). После «Сгладить»/«Сместить» список частей исчезает, скрытое снова видно, возвращаются двусторонняя отрисовка и освещённая текстура (штриховка у глаз). Решение: хранить части и `cull` при модели, пока не меняется число вершин (правки двигают вершины, топологию не трогают); нормали после правки пересчитывать только в изменённой области. Тест: открыть модель → сгладить область → `mesh()` всё ещё содержит `parts` и `cull`.
- [x] **2. «Показать «до»» сбрасывает скрытие.** Сделано: `before()` отдаёт те же поля (`_file_fields`); в Chrome скрытый торс остаётся скрытым в «до». Было: `before()` не отдаёт `parts`, `reloadMesh` чистит `HID`, после возврата всё видно. Решение: `before()` отдаёт те же `parts`/`cull`, клиент не трогает `HID` при показе «до».
- [ ] **3. Рамка выделяет скрытые части.** `Selection.box` берёт все вершины в коробке. Нужен список видимых вершин от клиента (или `hidden` в запросе) — рамка и кисть работают только по видимым. Кисть сейчас не перетекает между частями (части не сварены), но затравка — ближайшая вершина из всех, может попасть в скрытую.
- [ ] **4. Правки задевают скрытое.** Если вершины скрытой части уже в выделении, «Применить» двигает и их. Как в Blender: операции идут только по видимым выделенным вершинам.
- [ ] **5. Экспорт сливает модель в один меш.** `export_bytes('glb')` пишет одну `head` с атласом: нет частей, имён, исходных текстур, нормалей, скелета. В игру такую модель вернуть нельзя. Решение: при открытии «Вся модель» экспортировать по частям — те же узлы и имена, исходные материалы, UV обратно из атласа в ячейку каждой части, текстура части вырезается из атласа в исходном размере; скелет/веса переносить из исходного файла (вершины те же). Тест: открыть → сохранить без правок → геометрия, имена узлов и UV совпадают с исходным файлом.

## P2 — неудобно
- [ ] **6. Клик по модели выбирает часть.** Сейчас только через список. Alt+клик (или отдельный инструмент «Часть») → выбрать часть под курсором, строка в списке подсвечивается и прокручивается.
- [ ] **7. Горячие клавиши.** H — скрыть выбранные, Shift+H — только выбранные, Alt+H — показать все (не в полях ввода).
- [ ] **8. Отдельный раздел «Части».** Список сейчас внутри «1. Область» между кнопками кисти; при 17+ частях он вытесняет остальное. Вынести в свой раздел/вкладку над «Областью», свёрнутое состояние запоминать.
- [ ] **9. Группы в списке.** Голова / тело / руки / ноги / оружие — свернуть группу, скрыть группу одним кликом.
- [ ] **10. Своё имя хранится только в браузере** (localStorage). Сохранять в проект (рядом с моделью или в `asset.json`), чтобы видно было на другой машине.
- [ ] **11. Качество атласа.** При >4 частях ячейка 512 px: текстура палаша 2048 и любая >512 уменьшаются, рисование кистью идёт по уменьшенной. Ячейки по размеру исходных текстур (упаковка прямоугольников) или отдельная текстура на часть.
- [ ] **12. Тесты на механику частей** (есть `test_parts_after_edit` — п.1–2) (по правилу «свой тест на механику»): `test_parts_list` (имена, диапазоны, скрытие меняет индекс, подсветка не ловит луч), `test_parts_after_edit` (п.1), `test_parts_export` (п.5).
