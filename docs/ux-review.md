# Оценка интерфейса с точки зрения пользователя + сравнение с AstraForge

Дата: 2026-11-06. Оцениваются `/pipeline` (рабочая панель) и `/proto` (прототипы П1–П6).

## 1. Что не так в `/pipeline` (взгляд пользователя)
| Проблема | Почему мешает | Что делать |
|---|---|---|
| Всё построено вокруг шагов конвейера (colormatch, lama_seam…), а не вокруг цели «исправить это место» | пользователь думает «шея светлая», а не «запусти neckblur» | рабочее пространство вокруг модели; шаги — внутри инструмента, как параметры |
| Модель не выбирается в 3D: нельзя ткнуть в место и сказать «тут» | главная задача — точечные правки | выделение области (П2) как первоклассный объект |
| Жаргон: маска, UV, розетка, pad | непонятно без справки | подписи на языке результата: «шея», «шов», «глаз»; термины — во всплывающей подсказке |
| Долгие шаги без прогресса и отмены | непонятно, зависло или работает | прогресс по шагам, кнопка «Отмена», оценка времени |
| Результат применяется сразу | страшно трогать | «до/после», применить отдельной кнопкой, откат одним жестом (журнал) |
| Цвет — единственный сигнал оценки | не видно дальтонику | значок + число + слово |
| Устаревший eye_score.json, профиль сетки только после запуска | показывается неактуальное | считать при открытии, помечать «устарело» |
| Нет замены части одним жестом | главная цель сервиса | П5: перетащить донора на розетку |
| Мобильный вид и клавиатура не проверены | — | проверить; горячие клавиши (Z — отмена, B — кисть) |

## 2. Что учесть в выделении области (по запросу пользователя)
- Выделение — именованный объект (`selections` в `spec/asset.schema.json`), а не временная картинка: «левый глаз» вызывается снова, в том числе ассистентом.
- Три способа: кисть, рамка, «по части» (из `regions.json`); режимы добавить/вычесть, расширить/сузить, инвертировать.
- Выделять надо по **поверхности**, а не по 2D-экрану: не захватывать то, что закрыто (задняя сторона головы, другая сторона носа). Кисть работает по видимым граням + «сквозное» включается явно.
- Растушёвка края в мм (`feather_mm`), чтобы правка не оставляла шов.
- Инструмент и ассистент меняют только внутри области (`op.selection`); вне — затемнено и защищено.
- Хранение в двух видах: вершины (для геометрии) и маска в UV (для текстуры) — один и тот же выбор должен работать для обоих.

## 3. Сравнение с AstraForge (v0.4.x, по README и сайту; сам не запускал)
AstraForge (Snodrod/AstraForge, Windows + NVIDIA, локально, UI на en/ru) — **генератор**: картинка/текст → 3D (Hunyuan3D) → текстуры → риг → анимации → эффекты → Godot-пакет/спрайты. Объём установки ~30 ГБ (быстрая) / ~95–135 ГБ (полная), легкая ~3 ГБ.

| Возможность | AstraForge | Наш сервис (цель) |
|---|---|---|
| Создание модели с нуля из картинки/текста | да (главное) | нет, не цель |
| Правка готовой модели | импорт GLB/OBJ/STL; перемещение/поворот/масштаб, цвет, материал, примитивы, undo/redo | правка конкретных дефектов с оценкой качества |
| Выделение области / маска | **не описано**; нет вершинной правки и скульптинга (явно в списке «не поддерживается») | выделение — основа |
| Замена части (голову на тело) | прямо не заявлено; возможно через «Forge/kitbash» в Blender | главный жест (П5) |
| Критики качества (оценка глаз/сетки) | нет | есть, объясняют результат |
| ИИ-помощник | Ollama/OpenAI/Anthropic, только ограниченный набор проверенных действий | агент + обучение на правках пользователя и RL локально |
| Рига/анимации/эффекты | да | позже, перенос весов при замене части |
| Выход | GLB, OBJ, WebM, PNG, Godot, спрайты | GLB и игровой .gm |
| Лицензия | бесплатно для некоммерческого (PolyForm NC с 0.4.2), коммерческое — $5/мес | своё |

Вывод: AstraForge не конкурент, а **дополнение**: он делает новые модели, мы — управляемо чиним/пересобираем существующие. Что перенять: один экран-пайплайн со статусами этапов, горячие клавиши (W/E/R, Ctrl+Z), установщик со сканом ПК, ограниченный набор проверенных действий ассистента (у нас это схема операций `op.schema.json`), локальный сервер 127.0.0.1, ru/en. Чего у них нет и мы делаем: выделение области, замена части по розеткам, критики, обучение на правках.

Asset Forge (Kenney, $19.95) — киткашинг блоков, не про органические модели; пробной версии нет, сравнение только по описанию.

Не скачивал: установщик AstraForge 30+ ГБ потребовал бы Windows-машины и подтверждения пользователя; сравнение сделано по публичным README и сайту. Если нужно сравнение «руками» — поставить «Light» (~3 ГБ) или «Quick» на Windows-машину.

## 4. Проверка вживую: AstraForge 0.4.16 на Windows (2026-11-06)
Установлен в `C:\AstraForge` (профиль «лёгкий»). Запускал `runtime\node\node.exe server\index.mjs` через ssh-сессию, порт 3210 пробросил на Linux, снимал headless Chrome (3D-вид в снимке пуст — программный GL; панели видны).

Что видно в интерфейсе:
- Три колонки: слева **рабочее пространство** (вкладки-этапы: Создать, Кузница, Кости, Текстуры, Скульпт, Анимация, Эффекты, VFX, Спрайты, 2D, AI, Tripo), в центре 3D-вид с тулбаром (выбор / перемещение / вращение / масштаб / вписать), справа **список объектов сцены** (иерархия с глазками видимости) и свойства выбранного.
- Внизу таймлайн анимации; сверху: Проекты, Сохранить, Экспорт, undo/redo, скриншот, сетка.
- Подсказки горячих клавиш в правой панели (W/E/R/F); статус локального движка и GPU — карточкой справа внизу; подсказки мышью в углу вида.
- Каждый этап — короткий мастер: заголовок («Начните с идеи»), выбор «Что создаём?» (существо/предмет/корабль), загрузка изображения, ракурсы.
- Вкладка «Скульпт» есть: встроенный SculptGL (в 0.4.16; README старой версии это отрицает) — в отдельном окне, не в общем виде.
- Редактирование идёт по **объектам** (фюзеляж, кабина, крыло…), а не по области на поверхности: выделение по вершинам/маске в главном виде не нашёл (по исходникам смотрел только sculpt-файлы).

Выводы для нас:
1. Перенять: левая колонка этапов + центральный вид + правый список частей; undo/redo и скриншот в шапке; подсказки клавиш рядом; статус локального движка; мастер «заголовок → выбор → загрузка».
2. Список частей справа с глазками — готовая модель для «замены части» (П5): часть = строка списка, замену делать на строке.
3. Наш плюс: выделение области на поверхности, оценка «до/после» критиками, обучение на правках — у них этого нет. Скульпт у них отдельным окном — наш выбор области должен быть в основном виде.
4. Их слабое место: 12 вкладок — новичку неясно, с чего начать; нам держать 3–4 режима (Выделить / Править / Заменить / Сравнить).

## B3.1 (2026-11-06): долгие шаги
Замена головы идёт фоновой задачей: полоса прогресса, этап словами, оценка оставшегося времени, «Отмена» (модель не меняется до финального применения).

## B3.2: до/после
Кнопка «Показать «до»» переключает вид на состояние до последней правки; применять заново не нужно, откат остаётся «Отменить».

## B3.3: устаревшие оценки
Если модель или настройки новее оценки — красный баннер «Оценка устарела: …» над таблицей; в журнале /edit оценка помечена, когда после неё были правки.
