# Промт: как попросить Claude спланировать доработку панели

Панель — `/pipeline` (`pipeline.py` + `app.py`). Claude видит страницу сам: `./shot.sh [путь] [ширина] [высота] [файл]` делает
снимок headless Chrome (по умолчанию `/pipeline`, 1300×2400 → `/tmp/panel.png`, узкий вид — ширина 420), затем читает png.

## Промт (скопируйте, подставьте цель)

```
Режим: план, код пока не менять.
1. Запусти панель (python3 app.py --port 8770), сними ./shot.sh (широкий 1300 и узкий 420), прочитай снимки.
2. Пройди страницу как пользователь, который хочет <ЦЕЛЬ: например «подобрать настройки и выбрать лучшую голову»>:
   что непонятно, что не работает, что лишнее, чего не хватает. Сверь число на странице с файлами work/*.json.
3. Выдай план: таблица «проблема → где (файл:строка) → что сделать → как проверить снимком/curl», сорт по важности,
   у каждого пункта размер (S/M/L). Спорные решения — отдельным списком вопросов ко мне (не больше 3).
4. Запиши план в docs/plan.md, вопросы по самой голове — в docs/backlog.md. Жди моего «го» и потом иди по пунктам
   до конца: правка → снимок → коммит → следующий.
```
